# Универсальный мастер-промпт для создания сайта цифровой студии

> **Инструкция**: Скопируйте текст из блока ниже и отправьте вашему ИИ-агенту (Antigravity, Cursor, Windsurf, Claude, ChatGPT, Codex). Замените переменные в блоке `ИСХОДНЫЕ ДАННЫЕ` на свои.

---

```markdown
Ты работаешь как автономный senior product designer, UX-копирайтер и frontend-архитектор. Твоя задача: с нуля создать, локально протестировать и опубликовать на GitHub Pages конверсионный коммерческий сайт цифровой студии нового поколения.

ИСХОДНЫЕ ДАННЫЕ:
BRAND_NAME = "{{ НАЗВАНИЕ ВАШЕЙ СТУДИИ / ПРОЕКТА }}"
TAGLINE = "{{ СЛОГАН, НАПРИМЕР: Цифровая студия для бизнеса и авторов }}"
TELEGRAM_URL = "{{ ССЫЛКА НА ВАШ ТЕЛЕГРАМ ДЛЯ СВЯЗИ }}"
SHOP_URL = "{{ ССЫЛКА НА ВАШ МАГАЗИН ИЛИ КАТАЛОГ }}"
CHANNEL_URL = "{{ ССЫЛКА НА ВАШ ТЕЛЕГРАМ КАНАЛ }}"
REPOSITORY_NAME = "{{ ИМЯ РЕПОЗИТОРИЯ НА GITHUB }}"
GITHUB_USERNAME = "{{ ВАШ GITHUB USERNAME }}"

ТЕХНОЛОГИЧЕСКИЙ СТЕК И АРХИТЕКТУРА:
1. Фреймворк: Astro 5 (Static Site Generation), TypeScript, чистый Vanilla CSS.
2. Никаких тяжелых клиентских UI-библиотек (React/Vue) — только легковесный чистый JavaScript для интерактивности. Скорость отдачи < 300 мс.
3. Единый конфигуратор: Все тексты, ссылки, цены, сроки и метаданные должны храниться в одном строго типизированном файле `src/config.ts`.

ДИЗАЙН И ЭСТЕТИКА (iOS Liquid Glass 2025–2026):
1. Палитра: Глубокий обсидиановый фон (#06080d), неоновый изумрудный акцент (#00f29d), лазурный (#38bdf8), индиго (#818cf8).
2. Стекло: Матовые полупрозрачные панели `backdrop-filter: blur(30px) saturate(190%)` с зеркальной верхней кромкой `1px solid rgba(255, 255, 255, 0.15)`.
3. Тактильный отклик: Микро-сжатие интерактивных карточек и кнопок при нажатии `:active { transform: scale(0.975); }`.
4. Навигация: Стеклянная плавающая капсула в шапке с плавным Scrollspy (подсветка активной секции через IntersectionObserver).
5. Bento Accent Tinting: При наведении на карточки услуг активируется индивидуальный неоновый оттенок.

ОБЯЗАТЕЛЬНЫЕ СЕКЦИИ САЙТА:
1. Header: Моноширинный логотип, статусная плашка ONLINE, плавающее меню, CTA «Обсудить проект» и мобильное меню.
2. Hero + Интерактивный пайплайн: 
   - Заголовок и дескрипшн без клише и воды.
   - Вместо картинок-заглушек — интерактивный виджет запуска (Идея → Прототип → Сборка → Запуск).
   - SVG-граф с анимированным пульсирующим узлом текущего этапа и инспектор кода телеметрии.
   - Поддержка управления клавиатурой (стрелки) и Segmented Control на мобильных.
3. Services: 4 выразительных Bento-блока с микро-бейджами ориентировочных цен («от ... ₽») и сроков («... дней»).
4. Projects: Только реальные собственные продукты или инструменты студии (без выдуманных клиентов и фальшивых логотипов вроде Apple/Google).
5. Process: 4 понятных шага работы с конкретными осязаемыми артефактами каждого шага.
6. Shop Banner: Контрастный блок экосистемы с быстрым переходом в магазин/каталог инструментов.
7. FAQ: 5 актуальных вопросов с разворачиванием на семантическом `<details>/<summary>`.
8. CTA + Footer: Финальный призыв к действию и подвал со ссылками и копирайтом.

СЛОЙ ДЛЯ ПОИСКОВИКОВ И AI-АГЕНТОВ (LLM-Native Layer):
1. Семантический HTML5 с `lang="ru"`, метатегами Open Graph, Twitter Card и GEO-метками.
2. Разметка Schema.org (JSON-LD): ProfessionalService, WebSite, OfferCatalog с ценами и сроками, FAQPage.
3. Эндпоинты `llms.txt` и `llms-full.txt` (UTF-8 c BOM `\uFEFF`) со структурированным прейскурантом и инструкциями для Perplexity, GPTBot, ClaudeBot.
4. Файл `robots.txt` с открытым доступом для AI-ботов и ссылкой на `llms.txt`.

БЕЗОПАСНОСТЬ И ДЕПЛОЙ:
1. Настроить GitHub Actions workflow (`.github/workflows/deploy.yml`) для автодеплоя на GitHub Pages.
2. Указать `site: 'https://<username>.github.io'` и `base: '/<repo-name>'` в `astro.config.mjs`.
3. КАТЕГОРИЧЕСКОЕ ПРАВИЛО: Никогда не публиковать локальные или внутренние IP-адреса в README.md или коде.
4. Автономно собрать, протестировать в браузере и опубликовать в репозиторий.
```
