# Tropoklad Lab — Официальный сайт цифровой студии

Премиальный коммерческий веб-сайт цифровой студии **Tropoklad Lab**, специализирующейся на запуске сайтов, Telegram-ботов, AI-автоматизации и инструментов для создателей контента и бизнеса.

---

## 🚀 О проекте
Сайт построен по современной архитектуре **Static Site Generation (SSG)** с бескомпромиссными требованиями к скорости, типографике и визуальной подаче в стиле **Tactile Dark Tech (2025–2026)**.

### Особенности реализации
- **Быстрый стек**: Astro 5 + TypeScript + чистый авторский CSS (Vanilla CSS).
- **0 лишних зависимостей**: Без тяжелых библиотек и рантаймов — мгновенная загрузка (<300 мс).
- **Интерактивный запуск**: Интерактивная схема продуктового пайплайна (*Идея → Прототип → Сборка → Запуск*) на чистом коде и SVG.
- **Полная поисковая оптимизация (SEO + GEO + AI-Search)**:
  - Метатеги и Open Graph;
  - GEO-метки (регион, координаты, обслуживаемые зоны);
  - Schema.org разметка (JSON-LD) для `ProfessionalService`, `WebSite`, `FAQPage`;
  - Файлы `robots.txt` (доступ для Googlebot, Bingbot, OAI-SearchBot, GPTBot, PerplexityBot, ClaudeBot);
  - Файл `llms.txt` для нейросетевых агентов;
  - Динамический `sitemap.xml`.
- **Адаптивность**: Проверено на экранах 390px, 768px, 1440px и 1920px.
- **Доступность**: Поддержка `prefers-reduced-motion`, видимые фокусные состояния, семантическая разметка.

## 🛠️ Установка и локальный запуск

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск в режиме разработки
```bash
npm run dev
```
Сайт будет доступен по адресу `http://localhost:4321`.

### 3. Проверка типов
```bash
npm run check
```

### 4. Сборка production-версии
```bash
npm run build
```
Готовая статическая сборка будет сгенерирована в папку `dist/`.

### 5. Предпросмотр собранной версии
```bash
npm run preview
```

## ⚙️ Где менять тексты, ссылки и настройки

Все тексты, ссылки, метаданные и списки услуг вынесены в **один централизованный файл**:
👉 `src/config.ts`

### Основные параметры в `src/config.ts`:
- `links.contactUrl` — прямая ссылка для связи в Telegram (кнопки «Обсудить проект» и «Обсудить запуск»);
- `links.shopUrl` — ссылка на магазин цифровых инструментов и доступов к AI;
- `links.channelUrl` — ссылка на Telegram-канал студии;
- `brand` — название бренда, слоган, статус готовности к проектам;
- `services` — 4 блока услуг с описанием и преимуществами;
- `projects` — собственные продукты студии;
- `process` — этапы работы;
- `shop` — наполнение секции магазина;
- `faq` — список вопросов и ответов (автоматически обновляет и видимый блок, и разметку FAQPage JSON-LD);
- `seo.geo` — гео-настройки для поисковиков.

## 🌐 Публикация на GitHub Pages

Проект готов к автоматическому развертыванию через **GitHub Actions**:

1. Создайте публичный репозиторий на GitHub: `tropoklad-lab`.
2. Подключите удаленный репозиторий:
   ```bash
   git remote add origin https://github.com/<ваш-аккаунт>/tropoklad-lab.git
   git branch -M main
   git push -u origin main
   ```
3. В настройках репозитория на GitHub перейдите в **Settings → Pages → Source** и выберите **GitHub Actions**.
4. При каждом пуше в ветку `main` сайт автоматически собирается и публикуется по адресу:
   `https://<ваш-аккаунт>.github.io/tropoklad-lab/`

## 🌍 Подключение собственного домена (Custom Domain)

Чтобы привязать свой домен (например, `tropoklad.com`):

1. Укажите домен в `src/config.ts` в поле `siteConfig.links.customDomain` и в `astro.config.mjs` в поле `site`.
2. Создайте файл `public/CNAME` с именем вашего домена (например, `tropoklad.com`).
3. В панели управления DNS вашего домена настройте `CNAME` или `ALIAS` на `<ваш-аккаунт>.github.io` в соответствии со стандартной документацией GitHub Pages.
4. В настройках GitHub Pages включите **Enforce HTTPS**.
